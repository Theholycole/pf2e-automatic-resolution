# Phase 1 — GM corrections (cross-cutting)

This phase does not own an exclusive spell catalog. Use the [complete spell list](all-spells.md) and apply correction tests to each batch with saves, attacks, target eligibility, condition values or durations.

Test provisional rerolls, effective degree overrides, exclude/restore, owner/GM authority, stale revisions, secondary-result invalidation and locking after consequences. Save-bearing and multi-step batches require their own data checks; identical UI does not prove identical mechanics.
